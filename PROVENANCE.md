# PolyTrack archive provenance

## Scope

This archive contains the 13 requested numbered releases from `0.1.1` through `0.6.2`. Version `0.1.0` is intentionally excluded.

The top-level `sources/` directory is immutable local preservation storage and is ignored by Git. The public-facing extracted copies are under `versions/`. Raw artifacts are not required to understand provenance because their filenames, locations, SHA-256 hashes, and acquisition sources are recorded here.

The directory `C:\Users\Static\Documents\GitHub\Polytrack 0.6.2` is a separate modified project. It was not inspected, copied from, modified, or used as evidence for this archive.

## Authenticity and security limits

The review checked entry pages and JavaScript for obvious unrelated branding, injected scripts, proxy code, cheat markers, credential theft, cryptomining, and unexpected download behavior. No obvious malicious or unrelated injection was found. Platform integration strings, historical advertising SDK detection, Kodub endpoints, and PolyTrack's own `unblocked` configuration were present in some releases and are consistent with the preserved builds. This is a reasonable preservation audit, not a proof of mathematical purity.
