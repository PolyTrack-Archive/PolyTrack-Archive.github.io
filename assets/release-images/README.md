# Launcher image provenance

Every image in this folder is local, launcher-only material tied to its matching preserved PolyTrack version. No image came from a fan site, mirror, or generated artwork. The copies do not modify any historical game file.

For releases 0.1.1 through 0.4.2, the image is a locally captured screenshot of that exact preserved build's original main menu. For later releases, it is an original image asset contained in that exact preserved build.
