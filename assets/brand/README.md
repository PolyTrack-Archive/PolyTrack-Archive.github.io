# Archive brand assets

These files are used by the root archive launcher only. They are not loaded by, copied into, or used to alter any historical game version.

- `polytrack-official-logo.png` is the official PolyTrack cover artwork published by Kodub on the verified [PolyTrack itch.io page](https://kodub.itch.io/polytrack). It is stored locally for the launcher header.
- `polytrack-official-race.png` is an official PolyTrack gameplay screenshot published by Kodub in the same itch.io gallery. It is stored locally for the launcher hero and social-preview metadata.
- `favicon.svg` is a byte-for-byte copy of the original `versions/0.6.2/images/icon.svg` file, used only as the archive site's favicon.

The official PolyTrack artwork remains credited to Kodub. Archive layout and documentation are by StaticQuasar931.
